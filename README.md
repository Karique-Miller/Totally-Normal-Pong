## Overview

You're playing a game of pong then suddenly you notice something. Your opponent is good, really good. So good in fact it's impossible to beat them. So now you have no choice but to turn to violence. Use one of the 3 available weapons to defeat your opponent in this totally normal game of pong.

---

## Features

- **2 Game modes** – Choose between the standard mode or a slightly harder version (its actually impossible).

- **Simple Controls** – Just WASD to move, Spacebar to fire and Ctrl + R to reset. That's it!

## Motivation & Goals

Totally Normal Pong is my first complete game project.

## Installation

1. Download the .p8 file.
2. Keep it in a folder easy to acces.
3. Open Pico-8 education edition (https://www.pico-8-edu.com).
4. Type "load" then select the file.
5. Type "run" to launch the game
